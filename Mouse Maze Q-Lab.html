Mouse Maze Q-Lab

A mouse is somewhere in a maze. Somewhere there is cheese, and somewhere there are traps. Nobody tells the mouse where. It only learns from what happens when it moves, and it writes what it learns into a Q-table: one number for every square and every direction.

The Q-table

Each row is a square (a state). Each column is a move (an action). The number is the mouse's current guess of how good that move is from that square. Underlined = best known move. The highlighted row is where the mouse is now.

The mouse's personality

How far one experience moves a number in the table. 0 = never learns, 1 = believes only the latest experience.

Running it in class

  1. Round 1, map hidden. A volunteer drives the mouse while the class watches the table. Nobody knows where the cheese is. Stop after the first trap and ask: which number changed, and why only that one?
  2. Find the cheese a few times. Ask students to look at the squares next to the cheese, then two squares away. The good news spreads backward one step per try. That is Patience at work.
  3. Round 2. Click Watch one try a few times, then Practice 100 tries. Turn on Show best moves: the arrows are the mouse's strategy.
  4. Predict, then test. Before moving a slider, have students write down what they expect to happen.

Prediction questions

  1. Set Curiosity to 0 and click Forget everything. Practice 100 tries. Why can the mouse get stuck doing something mediocre?
  2. Set Patience to 0. Can the mouse still learn a route from the start? What does it learn?
  3. Train a mouse well, then click New random maze without forgetting. Is the old Q-table useful, harmful, or neither?
  4. Set Learning speed to 1, then to 0.05. Which mouse learns faster? Which is steadier?
  5. In the starter maze, the short way to the cheese runs past traps. Does the trained mouse take the risky route or the safe one? What changes that?
